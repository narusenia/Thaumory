# Thaumory 実装計画

要件は [requirements.md](requirements.md) を正とする。この計画書は進捗の正本であり、タスクを進めたら同じコミットで更新する。

## 進捗の書き方

- 状態: `[ ]` 未着手 / `[~]` 作業中 / `[x]` 完了 / `[-]` 見送り（理由を併記）
- タスク ID は `M<マイルストーン>-<番号>`。一度振った ID は変えない（削除する場合は `[-]` にする）
- 各タスクの「完了条件」を満たしたら `[x]` にし、サマリ表の数を更新する
- 実装中に要件が変わった場合は、先に `requirements.md` を更新してからタスクを直す
